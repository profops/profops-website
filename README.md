# ProfOps.dev

Engineering Magazine + Hands-on Lab covering DevOps, Platform Engineering, Cloud Native, SRE, AI and automation.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Cloudflare Pages

- Framework preset: **Astro**
- Build command: `npm run build`
- Build output directory: `dist`
- Production branch: `main`

Connect `profops/profops-website` through Cloudflare Pages Git integration. Set `profops.dev` under Custom Domains after the first successful deployment.

## Content

The initial site is a landing-page starter. Article and lab cards marked "Coming soon" are placeholders, not published tutorials. Add Markdown content collections and real lab repositories as content becomes available.
